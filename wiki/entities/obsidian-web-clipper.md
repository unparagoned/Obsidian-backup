# Obsidian Web Clipper

Browser extension for saving web pages into an Obsidian vault as Markdown. In this vault it feeds `raw/inbox` for the [[llm-wiki]].

## Configuration note

Per [[setup-obsidian-wiki]], the save folder lives in each **template** (gear icon → Templates → Default → *Note location*), not in General settings. Set it to the vault-relative path `raw/inbox` and choose the vault explicitly instead of "Last used".
